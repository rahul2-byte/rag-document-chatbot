# Demo video script (about 58 s, 1280x720)

One continuous take, recorded by `demo/record_demo.cjs` against the running apps. All waits are real
(nothing is sped up or cut). The only edit is a splice: the PDF opens in a real new browser tab, which
Playwright records as a separate video, and that clip is placed into the timeline for the exact seconds the tab was open.

Functions relate to the Privacy Framework?" in this run). If no Related chips appear within 8 s, the
script types "Which of those covers incident recovery?" instead.

## Re-record

1. Start both apps (chat on 127.0.0.1:7860, owner console on 127.0.0.1:7861). `data/` must hold the 3 PDFs.
2. Optional: move `logs/questions.jsonl` aside so "Recent questions" shows only the demo's questions.
3. Once, from the repo root, install Playwright and its Chromium (ffmpeg and ffprobe must be on PATH):

       npm install --no-save playwright && npx playwright install chromium

4. From the repo root (`DEMO_BACKUP_DIR` is optional):

       node demo/record_demo.cjs
       # or: DEMO_BACKUP_DIR=/some/tmp/dir node demo/record_demo.cjs

What the script does:
- Setup, not recorded: copies `data/` and `index/` to `DEMO_BACKUP_DIR` (default: `$TMPDIR/chatbot_demo_backup`),
  then removes NIST.CSWP.29.pdf through the owner console API (DELETE + rebuild) so the on-camera upload is real.
  The copy to upload is `demo/staging/NIST.CSWP.29.pdf` (gitignored); if it is missing, the script copies it from
  `data/` before removing the PDF.
- Records with Playwright 1.62 in headless full Chromium (`channel: 'chromium'`, which has the PDF viewer).
  A small grey dot shows the mouse pointer.
- Writes `demo/out/demo.mp4` (H.264, yuv420p, 30 fps) and page screenshots taken at the moment of each step:
  `frame_upload.png`, `frame_streaming.png`, `frame_cited_answer.png`, `frame_source_open.png`,
  `frame_followup.png`, `frame_refusal.png`, `frame_owner_panel.png`. It prints the timeline in video seconds.
- Finally, also on failure: if `data/` differs from the backup, or the status shows the wrong document count or a
  stale index, it restores `data/` and `index/` from the backup. It prints the final status.

Settings: `DEMO_ANSWER_TIMEOUT_MS` (default 60000) is the wait for each answer. `DEMO_KEEP_RAW=1` keeps the
raw Playwright `.webm` files in `demo/out/raw/`. The script fails if the video is 75 s or longer.
